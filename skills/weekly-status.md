# Weekly Status Update

## Input

Raw bullet-point notes — unformatted, in any order, written for yourself rather than an audience.

## Output

A leadership-ready update with exactly four sections, in this order:

1. **Shipped**
2. **In Progress**
3. **Blockers**
4. **Next Week**

## Rules

- Maximum 3 bullets per section. If more than 3 items belong in a section, keep the 3 most important and drop or merge the rest.
- Plain, declarative language. No jargon, no filler words ("leveraging," "synergy," "circle back").
- Each bullet is a complete, standalone statement — a reader skimming only that line should understand it without needing the raw notes.
- If a section has no items, write "Nothing to report" rather than omitting the section.
- Do not invent items, numbers, or outcomes that aren't in the raw notes.

## Example

**Input:**
- finished the comeback screen prototype, tested with 5 users
- still working on streak-freeze logic, eng says maybe done by friday
- waiting on design review for the new push copy
- notification fatigue research ongoing
- need to schedule review with marcus next week
- want to start drafting the experiment plan

**Output:**

**Shipped**
- Comeback screen prototype, tested with 5 users.

**In Progress**
- Streak-freeze logic — engineering estimates done by Friday.
- Notification fatigue research.

**Blockers**
- Push copy is waiting on design review.

**Next Week**
- Schedule review with Marcus.
- Start drafting the experiment plan.
